# DATABASE — SQLite schema (Phase 0)

Source: `packages/storage/src/schema.ts` (Drizzle). Migrations: `packages/storage/drizzle/` generated by `drizzle-kit generate` and committed. Apply with `runMigrations(db)` (idempotent).

Pragmas on open: `journal_mode=WAL`, `foreign_keys=ON`, `busy_timeout=5000`. WAL does not apply to `:memory:` databases, so persistence tests use a temp file.

Tables: `projects`, `workflows`, `tasks`, `task_dependencies`, `messages`, `events`, `settings`.

- CHECK constraints mirror `WorkflowState` / `TaskState` in contracts.
- `task_dependencies` forbids self-dependency (cycle detection beyond that is Phase 2).
- `messages` is `UNIQUE(task_id, sequence)`.
- `Repo.setTaskState` updates `tasks` and appends an `events` row in one transaction.
- Timestamps are ISO-8601 text.

Deferred (needed before multi-agent concurrency): `agents`, `sessions`, `artifacts`, `approvals`, `execution_runs`, `worktrees`, outbox/delivery ledger.
